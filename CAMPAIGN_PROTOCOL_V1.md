# Protocolo Congelado — LP/Campanha V1

## Hipótese
Empresários e líderes prestes a comprometer recursos em uma decisão relevante reconhecem valor em investigar a hipótese por trás dela antes da execução.

```text
Meta → LP → atenção → intenção → envio → OQP → diagnostic → proposal → sprint_paid
```

## OQP
Um lead só é OQP quando possui:
1. decisão/problema relevante;
2. consequência econômica/operacional/estratégica;
3. dados potencialmente investigáveis;
4. alguém com capacidade de agir.

## Gates V1
São priors experimentais, não benchmarks universais.

| Transição | Saudável | Atenção | Problema |
|---|---:|---:|---:|
| Meta click → LP view | >=80% | 70–80% | <70% |
| LP view → engaged 10s | >=55% | 40–55% | <40% |
| LP view → scroll 25 | >=60% | 45–60% | <45% |
| LP view → scroll 50 | >=35% | 25–35% | <25% |
| LP view → offer view | >=25% | 15–25% | <15% |
| LP view → CTA | >=6% | 3–6% | <3% |
| CTA → form start | >=65% | 45–65% | <45% |
| form start → submit | >=35% | 20–35% | <20% |
| LP view → submit | >=2.5% | 1–2.5% | <1% |
| submit → OQP | >=30% | 15–30% | <15% |

## Offer Acceptance Rate
```text
sessões com offer_view e CTA / sessões com offer_view
```
- >=15%: forte
- 8–15%: aceitável
- <8%: investigar oferta/prova/risco percebido

## Mínimos operacionais
- topo da LP: interpretar após ~100 LP views
- formulário: interpretar após ~20 form starts
- OQP: interpretar após ~10 submits ou evidência qualitativa forte
- compra: baixa frequência; interpretar caso a caso no início
